json-traversal

Describe the JSON you want. Get exactly that. Declarative, zero-mutation data extraction and filtering engine (published as select-json-by-json).

Package: json-traversal (select-json-by-json) Role: Declarative Data Filter GitHub ↗ npm ↗
The Story

Stop Writing Manual Mapping Loops

In real-world applications, raw business records (e.g. invoices, ledger items, voucher lists) contain dozens of nested fields. However, a table or form component only needs a specific subset of those fields.

Instead of writing repetitive, error-prone source.map(row => ({ item: row.X, price: row.Y })) code, you write a spec: plain JSON shaped exactly like the result you want.

Zero Mutation Guarantee: selectJson never touches or mutates your source data. It extracts and returns a brand-new object or array conforming strictly to your query spec.
In 30 Seconds

Declarative Query Spec in Action

import { selectJson } from "select-json-by-json";

const source = {
  DATE: "20261101",
  VOUCHERNUMBER: "INV-902",
  PARTYNAME: "Apex Distributors",
  "ITEMS.LIST": [
    { NAME: "Cable 10m", RATE: "120.00", QTY: "5", INTERNAL_ID: "x89" },
    { NAME: "Adapter",   RATE: "80.00",  QTY: "2", INTERNAL_ID: "x90" }
  ]
};

// Shape the result: keep only what UI needs
const spec = {
  VOUCHERNUMBER: true,
  "ITEMS.LIST": { NAME: true, RATE: true }
};

const result = selectJson(source, spec);
console.log(result);
// {
//   VOUCHERNUMBER: "INV-902",
//   "ITEMS.LIST": [
//     { NAME: "Cable 10m", RATE: "120.00" },
//     { NAME: "Adapter",   RATE: "80.00" }
//   ]
// }
