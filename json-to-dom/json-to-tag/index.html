The Story

The 6-Stage Assembly Pipeline

Building DOM elements manually requires setting properties, styling classes, attributes, datasets, and appending children in varied sequences. json-to-tag formalizes this into an exact 6-stage assembly pipeline:

Stage 0

createElement

Native W3C DOM or SVG namespace instantiation via document.createElement.

Stage 1

applyTextContent

Safe text assignment via element.textContent preventing HTML injection.

Stage 2

applyProperties

Direct object property assignment (e.g. value, disabled, checked).

Stage 3

applyAttributes

Standard attributes and dataset tokens (data-*, aria-*).

Stage 4

applyClassList

Splits class tokens and assigns them via element.classList.add.

Stage 5

appendChildren

Recursive compilation and attachment of child element trees.

Zero Dependencies & Zero Virtual DOM: Synthesizes real browser DOM elements directly at maximum speed without the memory overhead of a virtual DOM diffing engine.
Quick Example

Synthesizing Native Elements

import { buildSpecElement } from "@keshavsoft/json-to-tag";

const spec = {
  tagName: "button",
  classList: "btn btn-primary shadow-sm",
  textContent: "Confirm Order",
  attributes: {
    type: "button",
    "data-action": "confirm"
  }
};

// Returns native HTMLButtonElement
const button = buildSpecElement({ spec });
document.body.appendChild(button);
