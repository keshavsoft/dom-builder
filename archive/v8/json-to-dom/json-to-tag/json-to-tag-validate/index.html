The Story

Why Validate Before Compiling?

When building deep UI trees (such as table > colgroup > thead > tbody > tr > td), a silent error in a JSON spec — like a typo in tagName, a malformed attribute dictionary, or an illegal nesting — can cause browser runtime crashes that are painful to debug.

json-to-tag-validate solves this completely: it traverses the nested spec before any DOM instantiation occurs, verifying nodes against the standards defined in spec-repo.

Pinpoint Diagnostics: When something fails, the validator doesn't just return false. It pinpoints the exact node path (e.g. root.children[1].children[0]) and the reason for the failure.
API Example

Validating Nested Component Trees

import { validate } from "json-to-tag-validate";

const tableSpec = {
  tagName: "table",
  attributes: { class: "table table-hover" },
  children: [
    {
      tagName: "tbody",
      children: [
        {
          tagName: "tr",
          children: [
            { tagName: "td", textContent: "Valid Cell" }
          ]
        }
      ]
    }
  ]
};

const result = validate({ inJson: tableSpec });
console.log(result);
// { isValid: true, errors: [] }
