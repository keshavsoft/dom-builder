spec-repo

The canonical Single Source of Truth for valid HTML element specifications. Decouples tag templates from JavaScript compiler logic using pure serializable JSON.

Package: spec-repo Role: Tag Specification Catalog GitHub ↗ npm ↗
The Story

Why Decouple Tag Specs from Compiler Logic?

In traditional frontend libraries, HTML element definitions are hardcoded inside JavaScript helper functions or messy string templates. If a design token changes, or if a table row needs an extra CSS class, developers are forced to touch the compiler codebase.

spec-repo solves this fundamentally: every HTML component is defined as a pure, serializable JSON specification with zero dependencies and zero runtime code.

The Mental Model: spec-repo is the architectural blueprint. It defines what a valid <tr>, <th>, or <button> looks like. Compilers like json-to-tag read this blueprint and stamp out real DOM nodes.
Template Interpolation

Dynamic Parameter Placeholders

Specifications in spec-repo support declarative interpolation tokens that compilers hydrate with runtime data: 

{
  "buildHeader": {
    "tagName": "th",
    "classList": "text-uppercase fw-bold border-bottom",
    "textContent": "${columnName}"
  },
  "buildBodyCell": {
    "tagName": "td",
    "classList": "align-middle",
    "textContent": "${rowValue}"
  },
  "buildColGroup": {
    "tagName": "col",
    "attributes": {
      "style": "width: ${width};"
    }
  }
}
