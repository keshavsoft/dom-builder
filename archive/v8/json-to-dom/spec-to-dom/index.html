spec-to-dom

Zero-dependency container resolution and safe DOM mounting engine. Attaches synthesized native DOM nodes cleanly to target containers without risky innerHTML.

Package: spec-to-dom Role: Container Resolution & Safe Mounting GitHub ↗ npm ↗
The Story

Why Have a Dedicated Mounting Engine?

Creating DOM elements in memory is only half the battle. Once elements exist, attaching them to a web page typically introduces fragile glue code: checking if the container ID exists, deciding whether to append, prepend, or clean-replace existing children, and avoiding destructive innerHTML calls that blow away attached event listeners.

spec-to-dom solves this cleanly: it handles container resolution and node mounting with safe DOM APIs.

Target Resolution

Finds target container elements by HTML string ID or accepts native HTMLElement / DocumentFragment references.

Multiple Node Shapes

Mounts single elements, flat arrays of elements, NodeLists, or DocumentFragments consistently.

Configurable Append Modes

Supports append (default), prepend, or clean replacement without destroying sibling elements.

Security & Performance: By using native appendChild and prepend instead of parsing HTML strings, spec-to-dom eliminates XSS vectors associated with innerHTML.
Quick Example

Mounting Synthesized Elements

import { specToDom } from "spec-to-dom";

// Mount an element or array of elements into target element #user-panel
specToDom({
  buildSpec: userCardElement,
  targetHtmlId: "user-panel",
  appendPosition: "append" // or "prepend"
});
