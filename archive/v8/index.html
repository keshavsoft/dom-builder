Quick Example

Build a Table From Data

Define a component type, columns, and data — render cleanly into target element #my-table: 

<div id="my-table"></div>

<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter",
    columns: ["item", "qty", "amount"],
    data: [
      { item: "Rope", qty: 25, amount: 3000 },
      { item: "Net",  qty: 10, amount: 1250 }
    ],
    targetHtmlId: "my-table"
  });
</script>
Field Meanings:
type selects the component structure.
columns defines visible headers and keys.
data supplies row values.
targetHtmlId identifies the DOM container to mount into.
