# keshavsoft-json-to-tag — Product guide

**Capability group:** 05-DOM-Generation  
**npm package:** `@keshavsoft/json-to-tag`  
**Version in source archive:** `1.12.2`

## Purpose

Converts JSON tag specifications into native browser DOM elements.

## How it fits into DOM Builder

This repository is one capability in a larger pipeline. It should be understood together with its linked upstream and downstream packages rather than as a standalone table or DOM application.

Turns JSON tag descriptions into native DOM nodes, using traversal and validation support.
