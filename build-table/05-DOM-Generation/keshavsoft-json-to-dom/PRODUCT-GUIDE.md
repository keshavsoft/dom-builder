# keshavsoft-json-to-dom — Product guide

**Capability group:** 05-DOM-Generation  
**npm package:** `@keshavsoft/json-to-dom`  
**Version in source archive:** `42.1.5`

## Purpose

High-level orchestration package connecting JSON-to-tag construction with DOM mounting.

## How it fits into DOM Builder

This repository is one capability in a larger pipeline. It should be understood together with its linked upstream and downstream packages rather than as a standalone table or DOM application.

Coordinates json-to-tag generation and spec-to-dom mounting as a higher-level API.
