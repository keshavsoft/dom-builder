# DOM Builder Documentation Library

Open `index.html` in a browser to navigate the documentation.

## Contents
- `01-Instruction-System` — instruction contract, validation, and execution.
- `02-Data-Access` — source resolution, traversal, and destination writes.
- `03-Transformation-Engines` — primitive, one-dimensional, and two-dimensional transforms.
- `04-Table-Construction` — table tree building and options.
- `05-DOM-Generation` — catalog, validation, DOM creation, and mounting.
- `06-Architecture` — architecture overview, complete workflow, and declared dependency map.

Each repository folder contains:
- `PRODUCT-GUIDE.md` — newly prepared orientation and navigation.
- The original root README, where available.
- Selected authored documentation pages from the repository's `docs/` folder.

## Excluded intentionally
Source code, package implementation folders, `.git`, `node_modules`, generated distribution bundles, historical archives, and interactive playground/editor implementation files are not included. Documentation pages and relevant static documentation assets are retained.
