Engine 2: spec-to-dom

The second internal engine invoked by json-to-dom: resolving the target HTML element and safely mounting the synthesized DOM.

The Hand-Off in src/v42/index.js

// Line 9: Hand off to Engine 2
const container = specToDom({
    buildSpec,
    targetHtmlId,
    appendPosition,
    showLog
});

What Engine 2 Executes

Inside spec-to-dom/src/v2/index.js, the appendToDom logic focuses entirely on container manipulation:

1. Container Target Resolution

Locates the target HTML container using document.getElementById(targetHtmlId). Fails gracefully if the element does not exist.

2. Collection Detection

Detects whether buildSpec is a single DOM node or a multi-element collection (e.g. Array, NodeList, or HTMLCollection) to apply proper spread mounting.

3. Flexible Mount Positioning

Evaluates appendPosition:
• "prepend" → Inserts at the top via container.prepend().
• Default / replace → Clears container and attaches via container.append().

4. Returns Mounted Instance

Returns the live container element directly, enabling immediate inspection or event attachment by the caller.

Output of Engine 2: The fully mounted, interactive DOM element now living inside your web page at targetHtmlId.
