@keshavsoft/json-to-dom

A simple story

One UI. Three Approaches.

Every web interface ultimately becomes nodes in the browser's Document Object Model (DOM). @keshavsoft/json-to-dom is the engine that interprets abstract JSON tag specifications and converts them into real, native HTML elements mounted into the target container with zero innerHTML risks.

The Execution Chain: JSON Specification → @keshavsoft/json-to-dom → Native Browser HTML DOM.

Write the markup

02 · Vanilla JavaScript

Create nodes manually

Native DOM APIs create and append each node.

const div = document.createElement("div");
const label = document.createElement("label");
const text = document.createElement("p");

label.textContent = "Name";
text.textContent = "Test Content";
div.append(label, text);
Browser output

Test Content

03 · JSON to DOM

Describe, then build

JSON describes the tree; engine compiles to native DOM.

const spec = {
  tagName: "div",
  children: [
    { tagName: "label", textContent: "Name" },
    { tagName: "p", textContent: "Test Content" }
  ]
};

jsonToDom({ jsonSpec: spec, targetHtmlId: "app" });
Browser output

Test Content

Key insight: The visual result is 100% identical. The third approach converts the UI description into portable JSON data, allowing backend APIs, database catalogs, or pipelines to generate rich interfaces without frontend code churn.
