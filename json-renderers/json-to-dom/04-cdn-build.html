Step 04 of 04

Build & mount native DOM via CDN.

Connect your JSON specification to the @keshavsoft/json-to-dom engine. With zero Node.js and zero build steps, the browser compiles the specification tree directly into native DOM elements.

1 · Complete HTML Document Example

A standalone, ready-to-run HTML file you can use directly in your browser: 

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>json-to-dom CDN Demo</title>
</head>
<body>
  <!-- 1. Target container element in your page -->
  <div id="my-container"></div>

  <script type="module">
    // 2. Import jsonToDom directly via CDN
    import jsonToDom from "https://cdn.jsdelivr.net/npm/@keshavsoft/json-to-dom/+esm";

    // 3. Define the UI specification
    const spec = {
      tagName: "div",
      attributes: { id: "test-content", class: "card-body" },
      children: [
        { tagName: "label", textContent: "Name" },
        { tagName: "p", textContent: "Test Content" }
      ]
    };

    // 4. Synthesize and mount safely to target container
    jsonToDom({
      jsonSpec: spec,
      targetHtmlId: "my-container",
      appendPosition: "beforeend"
    });
  </script>
</body>
</html>

2 · Execution Pipeline

Zero innerHTML risks: @keshavsoft/json-to-dom accepts the abstract tag specification, validates it against allowed HTML element grammar, creates authentic browser elements via native document.createElement, and safely attaches them to your target HTML ID with zero unsafe string interpolation.
