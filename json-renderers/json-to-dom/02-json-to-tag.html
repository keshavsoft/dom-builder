Engine 1: @keshavsoft/json-to-tag

The first internal engine invoked by json-to-dom: converting abstract JSON blueprints into verified native DOM element trees.

The Hand-Off in src/v42/index.js

// Line 7: Hand off to Engine 1
const buildSpec = jsonToTag(jsonSpec);

What Engine 1 Executes

@keshavsoft/json-to-tag is a zero-dependency compiler designed specifically for tag tree validation and instantiation:

1. W3C Tag Catalog Validation

Checks tag names against tags.json. Enforces HTML grammar rules — ensuring void tags (like <input>, <hr>) never receive invalid children.

2. Native Node Instantiation

Creates genuine browser element instances via document.createElement(spec.tagName) — never string parsing or innerHTML.

3. Attribute & Class Filtration

Safely binds attributes (e.g. colspan, type, id) and applies classes from strings or token arrays without breaking event listeners.

4. Recursive Child Traversal

Recursively traverses spec.children, constructing nested hierarchies (like table → thead → tr → th) in a single fast, deterministic pass.

Output of Engine 1: A fully instantiated native in-memory DOM element tree (or DocumentFragment) stored in buildSpec, completely ready to be mounted into a web page container.
